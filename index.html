How to do

Icon Actions Instructions
Create a node Double click in the void
Create an edge Click on a node then CTRL+Click on the target node
Create a node with edge Click on a node then CTRL+Click on empty space (Add Shift for focus on the new node)
Delete (node/edge) Select a node/edge and press Ctrl+Delete or Ctrl+Backspace
Unselect (node/edge) Press Escape or Click again on the same node/edge
Multi selection (nodes/edges) Shift+Click to add/remove, or Left click + drag in empty space for box selection (Shift to add)
Change name (node/edge) Select an item then change value in Valeurs tab
Zoom Mouse wheel scroll
Move node Left click + drag
Move selected nodes Ctrl+Click + drag or Shift+Click + drag on one selected node
Move graph Right click + drag
Context menu Right click on graph, node, link or selection
Undo/Redo CTRL + Z / CTRL + Y
Create a self loop Select a node then ALT+Click on the same node

Tips: You can select nodes and edges by clicking on their labels
